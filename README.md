\# Library Management System



\## Description



Command-line-based Library Management System built using Java.



Features include: managing books and members, issuing and returning books, searching and sorting of books, saving library data, and viewing library statistics.



\## Technologies Used



\- Java 17

\- Maven

\- JUnit 5

\- CSV file



\## Prerequisites



Before running the application,



\- Install JDK 17 or higher version

\- Install Apache Maven



Check the installations by running the following commands in terminal:



```bash

java -version

mvn -version
