\# Problem Statement



\## Problem



Manual management of books, members, and book issue/return transactions might be cumbersome and error-prone in terms of keeping records in the library. A simple computerized solution is required for such purposes.



\## Scope



This project offers a Library Management System that is console-based and developed in Java language. This system includes the management of books, library members, book issue and return transactions, searching and sorting operations, data storage, and library statistics.



\## Target Audience



\- Small Libraries

\- Educational Institutes

\- Library Staff

\- Students who are learning Java programming



\## High-Level Features



\- Adding and removing books from the list

\- Searching and displaying books in the list

\- Adding and displaying library members

\- Issuing and returning books

\- Displaying currently issued books

\- Sorting of books in alphabetical order of their title or authors

\- Saving of the library data

\- Displaying library statistics

\- Validating user input and books/members availability
